# VisionHub Source Progress

VisionHub Source Progress 是给 **Chrome / Edge Web 浏览器**使用的 Manifest V3 扩展。它在真实源站 iframe 中检测原生 HTML5 video 元素的播放位置和总时长，将进度通过受校验的 postMessage 通道交回 VisionHub Web，并接受 VisionHub Web 发送的恢复位置。

它不运行在 Electron 桌面端，也不读取浏览器 Cookie。默认不会修改源站响应头；可选的“允许源站在 iframe 中播放”实验功能仅对用户已启用的源站、由已信任的 VisionHub Web 站点发起的子 iframe 移除 `X-Frame-Options` 与 `Content-Security-Policy` 响应头。该模式会降低 iframe 安全性，可能增加点击劫持风险或改变源站脚本策略，只应对自己信任且有权嵌入的源站临时启用；它不绕过 DRM、登录限制或付费限制。

## 安装（开发版）

1. 打开 Chrome 的 chrome://extensions，或 Edge 的 edge://extensions。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选中仓库中的 apps/web/extensions/source-progress 目录。
5. 打开 VisionHub Web 的某个播放页面，点击扩展图标。
6. 点击“信任此 Web 站点”。
7. 在检测出的 iframe 域名中选择需要处理的源站，并点击“启用所选域名”。
8. 刷新 VisionHub Web 播放页面后播放视频。扩展可以继续检测源站内部的嵌套 iframe；如发现新域名，再打开扩展并授权该域名。

该扩展使用按需申请的 HTTPS 主机权限。只有用户明确选中的源站域名会被注册为 content script 运行范围。安装扩展不代表所有网站都被自动授权。

## iframe 嵌入兼容模式（默认关闭）

在扩展弹窗中先信任当前 VisionHub Web 站点、启用所需源站域名，再勾选“允许已启用源站被 iframe 嵌入”。扩展通过 Manifest V3 `declarativeNetRequest` 仅为已启用源站的 `sub_frame` 响应移除 `X-Frame-Options` 和 `Content-Security-Policy`，并仅匹配由已信任 VisionHub 站点发起的请求；不会对所有网站或顶层导航全局生效。关闭选项会删除这组动态规则。

**安全注意：** 移除完整 CSP 响应头不只是允许嵌入，还会移除其他 CSP 限制。只在确实需要、理解风险并信任源站时启用；不建议长期或全局开启。浏览器本身、扩展权限、源站脚本和其他响应策略仍可能影响最终结果。

## 当前支持与边界

- 从可见的原生 HTML5 视频元素选出主播放器，读取当前播放位置和总时长。
- 源站播放器就绪后，自动只保留播放器容器（包括容器内的控制栏），隐藏页面导航、推荐内容、广告位及其他周边 DOM；对嵌套播放器 iframe 也会在外层页面隐藏其他区域。
- 纯播放器模式通过添加扩展专用属性和 CSS 隐藏其他元素，而不是直接删除节点，以降低破坏源站播放器脚本、全屏和控制栏的风险。页面动态新增元素时会重新应用隔离样式。
- 拖动进度条、暂停、结束时主动同步，播放期间约每 2 秒同步一次。
- 如果 VisionHub 已有该片目/剧集的本地观看进度，扩展会在源站视频元数据可用后开始恢复，并在播放器初始化期间有限重试；确认恢复完成前不会把暂时回到 0 的进度同步覆盖掉原有观看记录。若用户主动拖动进度条，则停止自动恢复。
- 进度复用 VisionHub Web 的现有本地观看历史，因此首页“继续观看”也可以使用保存的源站进度。
- 它不会自动播放，仅恢复时间点，不会强制点击播放。若视频原本正在播放，扩展会在源站 iframe 的主世界中优先拦截失焦/切换窗口期间对 HTMLMediaElement.pause() 的程序化调用，并在窗口重新获得焦点后继续进行有限恢复检查。播放器内明确点击播放/暂停控件或使用播放器键盘快捷键时，会优先尊重用户操作。若源站通过浏览器原生媒体控件或其他不经过 JavaScript pause() 的内部机制暂停，仍会尝试恢复；浏览器自动播放策略仍可能拒绝程序恢复。
- 自定义 canvas 播放器、未授权的 iframe 域名、无 HTML5 video 的播放器可能无法读取进度。
- 在浏览器沙箱、扩展访问权限或源站嵌入策略阻止扩展运行时，视频播放仍可继续，但不会自动同步进度。
- 若源站内层 iframe 使用了另一个域名，需要对该域名单独授权。每个框架都必须匹配已启用的 origin。
- 进度存在当前 Web 站点的本地存储中，不会自动同步到别的浏览器、设备或用户账户。

## 通信与权限模型

- VisionHub Web 为每个播放实例生成随机 token，并且只接受来自当前 iframe 的消息。
- 内容脚本只接受来自用户已信任的 Web 源站初始化命令；嵌套 frame 的命令沿已授权的 frame 层级转发。
- 恢复位置和播放进度都通过 postMessage 桥传递；扩展不需要读取 VisionHub 的页面 DOM 或本地存储。
- 只请求用户选中的 HTTPS 源站主机权限。请仅授权自己信任的源站。


## 源站播放器控制栏

- 源站播放器开始播放后，控制栏默认显示约 1.8 秒，闲置后自动隐藏；鼠标、触控或键盘操作时重新显示，暂停或缓冲时保持可见。
- 扩展会识别常见播放器中的快进、快退按钮，并隐藏这些按钮；识别范围限定在实际可操作控件，避免误隐藏设置菜单或其内容。源站进度同步与续播逻辑不变。
- 控件隐藏通过扩展专用 CSS 属性实现，不删除播放器节点，以减少对源站播放器事件和播放状态的影响。设置、清晰度、字幕和倍速菜单打开期间会保持控制栏可见；菜单关闭后再恢复自动隐藏。源站 Plyr 的主题色同步为主站使用的荧光绿（`#c7f36b`），覆盖进度条填充/缓冲轨道、中心播放按钮、音量滑块、控制图标、悬停状态、设置菜单与进度提示。使用 Plyr 提供的 CSS custom properties，并按 Plyr 实际使用的选择器显式覆盖 range 输入的 `color`、视频/音频控件的 `background` 与 `color`、已选菜单单选项 `::before` 的 `background`，同时覆盖中心播放按钮和菜单面板。Plyr 的 `controls` 和 `settings` 是初始化选项；扩展不重建源站已有的播放器实例，以避免破坏源站状态和事件绑定。由于不同源站实现差异，仍需用实际播放器验证；浏览器原生视频控件的内部按钮不一定能被扩展访问。
